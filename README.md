# hauntedhouse
**Escape the Haunted House**

Jogo digital de escape room com tema de Halloween, criado para revisar conteúdos de inglês em sala de aula. Os alunos, em grupos, ficam "presos" em uma casa assombrada e precisam resolver 6 salas em 15 minutos antes que a vela se apague.

**Como funciona**
Em cada sala, a turma clica nos objetos da cena (um espelho, um caldeirão, um relógio), e cada objeto esconde uma pergunta em inglês. Ao resolver todos, a porta se abre e a sala entrega uma letra secreta. As letras chegam fora de ordem e, na última sala (The Crypt), os alunos precisam reorganizá-las para formar a palavra que abre o cadeado final e permite a fuga.

**Conteúdos de inglês trabalhados**
- Pronouns
- Adverbs of frequency
- Present continuous
- Prepositions of time (in, on, at)
- Clock (horas)

A última sala faz uma revisão geral, com uma pergunta de cada assunto.

**Recursos**
- Banco com 8 perguntas por sala, sorteando 4 a cada partida, o que permite jogar mais de uma vez sem repetir o mesmo jogo
- Palavra secreta sorteada a cada partida
- Botão de áudio (🔊) que lê a pergunta em inglês, para treinar listening
- Efeitos sonoros, com botão para silenciar
- Dicas por sala, contabilizadas no resultado final
- Cenas diferentes para cada sala e animação de porta se abrindo
- Manual do jogo e créditos dentro da própria página
- Tela final com tempo usado e número de dicas

**Tecnologia**
Página única em HTML, CSS e JavaScript puro, sem bibliotecas externas. Os sons são gerados pelo próprio navegador (Web Audio API) e a leitura em voz alta usa a síntese de voz do navegador. Funciona em computador e celular.
